# GameStore

Приложение для развертывания локального сервера по работе с упрощенной версией *"онлайн"* магазина игр. В нем можно получать, создавать, удалять и обновлять игры и категории игр. Также реализована регистрация пользователей и вход в учетную запись. Можно совершить заказ, посмотреть его и сделать возврат. Также существует кошелек, который можно пополнить. Для приложения написан простой сайт в `wwwroot` для удобной работы. По умолчанию есть сидинг БД. А добавление новых игр упрощено с помощью парсера ссылки игры со Steam.

## Стек

`ASP.NET Core`, `PostgreSQL`, `Minimal API`, `EF Core`, `JWT`, `FluentValidation`, `Docker`

## Как запустить

- Установить и запустить Docker Desktop
- Из корня проекта выполнить: `docker compose up -d`
- Единожды установить `Jwt:Key`, используя команду `dotnet user-secrets set "Jwt:Key" "CustomKey" --project .\GameStore.Api\GameStore.Api.csproj`
- Запустить приложение с помощью команды: `dotnet run --project .\GameStore.Api\GameStore.Api.csproj`
- Открыть в браузере: [Swagger](http://localhost:5104/swagger) или [Сайт](http://localhost:5104)
- **API находится вне контейнера**
- **Postgres слушает localhost:5432**

## Сидинг БД по умолчанию

- При первом запуске, если в БД нет записей, - будет произведен сидинг таблиц БД.
- Будут добавлены категории и игры по умолчанию
- Будет добавлен один пользователь с ролью Admin: email:**admin@gmail.com** и password:**admin123**
- При вызове: `docker compose down -v` том с БД сотрется - данные снова засидятся, но все данные потеряются, которые были добавлены вручную

## Регистрация, вход и JWT

- Для работы некоторых запросов нужна авторизация
- Для этого нужно войти в учетную запись и получить токен авторизации
- Его можно задать в Swagger для удобства
- Далее можно будет оформлять и получать заказы

## Сценарии работы c [Swagger](http://localhost:5104/swagger)

### Регистрация

- Найти endpoint `POST /register`
- Ввести email и пароль

### Аутентификация

- Найти endpoint `POST /login`
- Ввести email и пароль
- Из ответа взять поле Token
- В самом верху страницы найти кнопку Authorize
- Ввести Token в поле и нажать Authorize

### Оформление заказа (необходима аутентификация)

- Найти endpoint `POST /orders`
- Ввести данные о заказах (gameId и quantity)

### Просмотр заказов (необходима аутентификация)

- Найти endpoint `GET /orders`
- Получить список заказов

### Просмотр конкретного заказа (необходима аутентификация)

- Найти endpoint `GET /orders/{id}`
- Ввести id заказа
- Если заказ принадлежит пользователю, то в ответе придет информация о заказе, иначе - `404`

### Работа с играми и категориями (необходима аутентификация и роль для некоторых операций)

- Существует общий доступ к каталогу через `GET /games`, `GET /games/{id}`, `GET /categories`, `GET /categories/{id}`
- Редактирование игр и категорий доступно только пользователям с ролью `"Admin"`
- Поддерживаются операции `POST`, `PUT`, `PATCH`, `DELETE`
