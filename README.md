# GameStore
Приложение для развертывания локального сервера по работе с базовой версией онлайн магазина игр.
В нем можно получать, создавать, удалять и обновлять игры и категории игр. Также реализована регистрация пользователей и вход в учетную запись. Можно совершить заказ и потом его посмотреть.

## Стек
ASP.NET Core, PostgreSQL, Minimal API, EF Core, JWT, FluentValidation

## Как запустить
- Указать в appsettings.json в GameStore строку подключения для базы данных.
- Все команды из корня запускать с --project .\GameStore.Api\GameStore.Api.csproj либо из папки GameStore.Api
- Создать Jwt:Key c помощью dotnet user-secrets set "Jwt:Key" "YourKeyIsHere"
- Выполнить обновление БД c помощью dotnet ef database update
- Запустить приложение с помощью команды: dotnet run
- Открыть в браузере: http://YourHost:YourPort/swagger/index.html, где вместо YourHost и YourPort указать ваши значения

## Регистрация, вход и JWT
- Для работы некоторых запросов нужна авторизация
- Для этого нужно войти в учетную запись и получить токен авторизации
- Его можно задать в Swagger для удобства
- Далее можно будет оформлять и получать заказы 

## Сценарии работы

Открыть http://YourHost:YourPort/swagger/index.html

### Регистрация
- Найти endpoint POST /register
- Ввести email и пароль

### Аутентификация
- Найти endpoint POST /login
- Ввести email и пароль
- Из ответа взять поле Token
- В самом верху страницы найти кнопку Authorize
- Ввести Token в поле и нажать Authorize

### Оформление заказа (необходима аутентификация)
- Найти endpoint POST /orders
- Ввести данные о заказах (gameId и quantity)

### Просмотр заказов (необходима аутентификация)
- Найти endpoint GET /orders
- Получить список заказов

### Просмотр конкретного заказа (необходима аутентификация)
- Найти endpoint GET /orders/{id}
- Ввести id заказа
- Если заказ принадлежит пользователю, то в ответе придет информация о заказе, иначе - 404

### Работа с играми и категориями (необходима аутентификация и роль для некоторых операций)
- Существует общий доступ к каталогу через GET /games, GET /games/{id}, GET /categories, GET /categories/{id}
- Редактирование игр и категорий доступно только пользователям с ролью "Admin"
- Поддерживаются операции POST, PUT, PATCH, DELETE
